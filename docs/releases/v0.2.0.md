**从这一版开始支持在线升级。** 已经装了 v0.1.x 的玩家请手动下载安装这一次，以后的版本会在游戏里自动下载，并提示「重启并更新」。

## 新增

- **在线升级**：进入主菜单后在后台检查新版本并下载，下载好后点「重启并更新」即可；对局中不会打扰。
  - 更新包带签名并逐字节校验，签名不对、文件不完整都不会安装；替换失败会自动恢复旧版本。
  - 游戏装在不能写入的位置（比如需要管理员权限的目录）时，只提示有新版本，并给出下载页。
  - 启动参数加 `-- --no-update` 可以关闭。
- **中文界面**：菜单、大厅、计分板、提示和错误信息改为中文，并补上中文字体。
- 主菜单显示当前版本号。

## 首次运行

- **macOS**：安装包只做了 ad-hoc 签名，没有经过苹果公证。第一次请右键点击 `Tank 3D.app` →「打开」；如果提示已损坏，执行 `xattr -dr com.apple.quarantine "Tank 3D.app"`。建议放在「应用程序」或自己的文件夹里，自动更新需要能写入它所在的目录。
- **Windows**：SmartScreen 提示时选「更多信息」→「仍要运行」。不要放在 `C:\Program Files` 下，否则无法自动更新。
- **防火墙**：首次运行时允许游戏接收网络连接（UDP 27015）。
