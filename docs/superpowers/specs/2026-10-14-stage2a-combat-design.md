# 阶段 2A：战斗核心设计

日期：2026-10-14
状态：已确认
上级文档：[第三人称坦克 PVP 总体设计](2026-10-13-third-person-tank-design.md) §4.3、§4.4、§5.1～§5.4。本阶段是总体设计 §12 中“阶段 2 战斗”拆出来的第一部分。

## 1. 拆分与范围

阶段 2 拆成三个小阶段，每个做完都可以试玩：

| 小阶段 | 内容 |
|---|---|
| **2A 战斗核心**（本文） | 血量、装甲盒、穿甲弹和高爆弹的击穿与跳弹、散布和缩圈、换弹种、弹药、击毁与复活、静止靶车、命中提示、伤害数字、击毁效果、界面 |
| 2B 车型 | 轻坦、重坦、坦克歼击车的数据和玩具外观；试驾场里可以切换车型 |
| 2C 可破坏物 | 砖墙、石墙、栅栏、草丛被毁，瓦砾；重坦撞倒砖墙 |

本阶段不做：

- 新车型；
- 墙、栅栏和草丛的破坏，炮弹仍然穿过草丛；
- 会还击的敌人，所以玩家自己的血量只做显示；
- 跳弹后的二次弹道；
- 部件损伤和乘员受伤。

## 2. 做法

所有战斗规则写在 `Tank.Sim` 里，包括命中、击穿、伤害、散布和击毁。客户端只根据仿真发出的事件做表现。需要随机的地方，种子都由 `(tick, tankId, shotIndex)` 推出，同样的输入总得到同样的结果。这样阶段 4 联网时，服务器和客户端用的是同一套代码，不需要重写。

## 3. 仿真层

### 3.1 车型数据（`TankSpec`）

新增字段如下。本阶段只填中坦，数值取自总体设计 §4.4。

| 字段 | 中坦数值 |
|---|---|
| `MaxHealth` | 900 |
| `Caliber`（mm） | 85 |
| 车体装甲盒 | 局部坐标中的盒子：长 6.2 m、宽 3.2 m，从离地 0.3 m 到 1.74 m，盒心在车体中心。装甲（mm）：前 90、侧 60、后 40、顶 20、底 20 |
| 炮塔装甲盒 | 局部坐标中的盒子：2.9 m × 2.9 m，从 1.68 m 到 2.8 m，盒心在炮塔座圈上，随炮塔转动。装甲（mm）：前 120、侧 80、后 50、顶 25、底 25 |
| 穿甲弹 | 穿深 175、伤害 220、初速 780 m/s |
| 高爆弹 | 穿深 45、伤害 280、爆炸半径 3 m、初速 624 m/s（穿甲弹的 0.8 倍） |
| 载弹量 | 穿甲弹 40，高爆弹 15 |
| 百米散布 | 0.36 m |
| 瞄准缩圈时间 | 2.1 s |
| 散布扩大系数 | 全速行驶 +2.0，车体全速转向 +1.5，炮塔全速转动 +1.0，每次开炮 +3.0 |

装甲盒和玩具外观分开定义，只需要大致对齐。原 `ShellSpeed` 字段由两种炮弹各自的初速取代。

测试校验每一项都是合法值：所有数值为正，装甲盒落在车体占地范围内，炮塔盒在车体盒之上。

### 3.2 坦克状态（`TankState`）

新增：

- `Health`
- `IsDestroyed`
- `Ammo`：当前弹种，`AP` 或 `HE`
- `ApLeft`、`HeLeft`：两种炮弹的剩余发数
- `Bloom`：散布扩大量，0 表示圈缩到底

### 3.3 输入（`InputCmd`）

新增 `Ammo` 字段，表示想用的弹种。它和当前弹种不同时：

1. 切换到新弹种；
2. 装填计时重新从整个装填时间开始。

非法值按“不切换”处理，仍然在 `Sanitize` 里清洗。当前弹种没有剩余弹药时，按开火无效。

### 3.4 散布（`Combat/Dispersion`）

- 每 tick 算出这一刻的“扩大目标值”：
  `目标 = 2.0 × |车速| / 最高速 + 1.5 × |车体转速| / 最高转速 + 1.0 × |炮塔转速| / 最高转速`
- `Bloom` 低于目标时，立即升到目标。
- `Bloom` 高于目标时，按时间常数 τ = 缩圈时间 / 3 指数衰减到目标。所以停下来后，大约一个缩圈时间就基本收拢。
- 开火后 `Bloom += 3.0`。
- 当前散布圈在 100 m 处的半径 = 百米散布 × (1 + `Bloom`)。
- 开火时取偏移：
  - 角度均匀随机；
  - 半径 = 圈半径 × u，u 在 [0, 1) 内均匀随机。这样落点更集中在中心附近。
  - 偏移换算成炮口方向上的偏航和俯仰的小偏转。
  - 随机数由 `(tick, tankId, shotIndex)` 推出。

### 3.5 命中检测

- 炮弹每 tick 的飞行线段除了对地形和岩石求交，还要对每辆坦克的两个装甲盒求交。射手自己的坦克除外。
- 装甲盒是三维有向盒，姿态取自 `TankPose`：车体的高度、俯仰、侧倾，炮塔盒再加上炮塔转角。
- 所有命中按距离取最近的一个。
- 求交返回四样东西：命中点、命中面的外法线、命中的是哪一面（前、侧、后、顶、底）、命中的是车体还是炮塔。

### 3.6 穿甲弹（`Combat/Penetration`）

1. 入射角 θ 是炮弹飞行方向的反方向与命中面法线的夹角。
2. 跳弹条件：θ > 70°，并且口径 ≤ 3 × 装甲厚度。跳弹不造成伤害，炮弹消失。
3. 等效装甲 = 厚度 / cos θ。
4. 本发穿深 = 标称穿深 × 随机(0.75, 1.25)。
5. 本发穿深 ≥ 等效装甲时击穿，伤害 = 标称伤害 × 随机(0.75, 1.25)，四舍五入取整。否则未击穿，没有伤害。
6. 两个随机数都由 `(tick, tankId, shotIndex)` 推出，并各自加上不同的偏移。

### 3.7 高爆弹

**直接命中坦克**：

- 先按穿甲弹的规则判断，但高爆弹不会跳弹。
- 击穿：给满额伤害，带随机浮动。
- 未击穿：伤害 = 标称伤害 × 0.5 − 等效装甲 × 1.1，最低为 0。
- 无论结果如何，命中点都会爆炸，产生溅射。被直接命中的那辆坦克不再计算溅射伤害。

**打中地形或岩石**：在命中点爆炸。

**溅射**：

- 对象是爆炸半径内的其他坦克，射手自己除外。
- 距离 d 取爆炸点到该坦克车体盒的最近点。
- 伤害 = 标称伤害 × 0.5 × (1 − d / 半径) − 最薄一面的装甲 × 1.1，最低为 0，取整。
- 伤害大于 0 才发事件。

### 3.8 血量、击毁、复活与补给

- 受到伤害后扣 `Health`。降到 0 或以下时：
  - `Health` 置为 0，`IsDestroyed` 置为 true；
  - 发出“坦克被击毁”事件。
- 被击毁的坦克：
  - 忽略所有输入，不能移动，也不能开炮；
  - 仍然参与碰撞，仍然挡炮弹，但不再受伤；
  - 打中它时，穿甲弹消失，高爆弹照常爆炸，溅射仍然会伤到附近的其他坦克。
- `Simulation.Revive(tankId)`：
  - 血量回满，`IsDestroyed` 清掉，`Bloom` 归零，装填清零；
  - 发出“坦克复活”事件。
- `Simulation.Restock(tankId)`：两种弹药补满到载弹量。

### 3.9 事件

`GameEvent` 增加四个字段：

- `TargetTankId`
- `Result`：`HitResult` 枚举，取值为 `Penetrated`、`Ricochet`、`NotPenetrated`
- `Damage`
- `Ammo`：炮弹的弹种

| 事件 | 时机 | 主要内容 |
|---|---|---|
| `ShellFired` | 开火 | 射手、炮弹、位置、速度、弹种 |
| `ShellExploded` | 高爆弹爆炸，或任何炮弹打中地形或岩石 | 位置 |
| `TankHit` | 炮弹直接命中坦克 | 目标、结果、伤害、命中点、命中面法线（借用 `Velocity` 字段） |
| `SplashDamage` | 溅射造成伤害 | 目标、伤害、位置 |
| `TankDestroyed` | 血量归零 | 目标、击毁者（`TankId`） |
| `TankRevived` | 复活 | 目标 |

## 4. 试驾场

### 4.1 靶车

- 在 `SandboxMap` 中新增 `TargetSpots`：6 个位置和朝向。要求：
  - 距出生点 30～200 m；
  - 在平地上，不与石头和草丛重叠；
  - 不挡住出生点到大山的通道。
- 6 个靶车相对出生点的朝向分别是：
  1. 正面对着出生点；
  2. 侧面对着出生点；
  3. 斜 45°；
  4. 车尾对着出生点；
  5. 半躲在一块石头后面；
  6. 放在远处 180～200 m。
- 测试校验以上要求。
- 靶车都是中坦，输入全为零。被击毁 10 秒后，由 `SandboxMain` 调用 `Revive`。

### 4.2 外观与表现

| 内容 | 做法 |
|---|---|
| 靶车颜色 | 蓝灰色 `Palette.TargetBody` #6F8FB5。`TankPaint` 按坦克选用颜色，玩家仍然是橙色 |
| 头顶血条 | 卡通胶囊形血条，屏幕空间显示。只在 250 m 内且在画面中时显示，满血时也显示 |
| 命中提示 | 命中点弹出带描边的卡通大字，弹跳后淡出：红色“击穿！”、黄色“跳弹！”、灰色“未击穿”。用对象池，不在每一发时分配 Tween |
| 伤害数字 | 例如“-220”，从目标头顶往上飘后淡出。溅射伤害用小一号的字 |
| 击毁 | 卡通爆炸。圆顶炮塔带着炮管转着圈飞起约 4 m，再落到车旁地面（纯表现，按抛物线插值，不参与碰撞）。车身通过 `tank_toon` 的焦黑参数渐变成焦黑色 #2B2622，并持续冒黑烟。复活时炮塔归位，焦黑和黑烟消失 |
| 曳光 | 穿甲弹为黄色（`Palette.Flash`），高爆弹为橙色（`Palette.Fire`） |
| 散布圈 | 准星外加一个圆圈。半径是当前散布圈在瞄准点距离上的投影，随 `Bloom` 变化 |
| 左下角面板 | 新增玩家血条；弹药栏“1 穿甲 40 / 2 高爆 15”，高亮当前弹种，弹药为 0 时变灰；装填显示保持不变 |
| 按键 | 1 换穿甲弹，2 换高爆弹，R 补满弹药（仅试驾场） |

## 5. 验收

1. **自动测试**：
   - 装甲盒求交：前、侧、后、顶、底各一个用例；炮塔转动后命中面正确；车体倾斜后命中面正确；
   - 跳弹的边界：69° 和 71°；3 倍口径的例外；
   - 等效装甲的计算；
   - 随机浮动在 ±25% 以内，并且同一种子结果相同；
   - 高爆弹：击穿时的伤害、未击穿时的伤害公式、溅射随距离衰减、不伤自己；
   - 散布：停下后约一个缩圈时间内收拢；开火时扩大；同样的种子得到同样的偏移；
   - 换弹种会重新装填；弹药用完后不能开火；`Restock` 补满；
   - 击毁：不能移动、不能开炮、仍然挡炮弹、不再受伤；`Revive` 恢复正常；
   - 事件的字段内容正确；
   - 靶车位置满足 §4.1 的要求。
2. **截图**：
   - 击穿、跳弹、未击穿各一张；
   - 伤害数字；
   - 炮塔飞起的瞬间；
   - 焦黑的残骸；
   - 新的左下角面板；
   - 散布圈分别在扩大和收拢时各一张。
3. **帧率**：关掉垂直同步后，环视和自由镜头都在 60 帧以上。
4. **试玩**：由用户确认。打靶车能看到三种结果和伤害数字，击毁时炮塔会飞起，散布的变化明显。
