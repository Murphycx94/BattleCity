# 01 · 玩法设计

## 1. 设计原则

- **手感忠于原作**：四方向移动、转向时贴齐网格、子弹可以互相抵消、砖墙可以被局部打穿、守护老鹰基地。
- **3D 只做表现**：所有玩法判定都在 XZ 平面的二维网格上完成，Y 轴只用于渲染和特效。这样网络状态小、判定确定、公平性好（见 [03-netcode](03-netcode.md)）。
- **为多人扩展**：原作最多 2 人合作，本作扩展为 2～8 人，加入对战模式。

## 2. 游戏模式

| 模式 | 人数 | 说明 |
|---|---|---|
| **合作闯关**（Co-op Campaign） | 1～4 | 原作玩法：每关 20 辆 AI 敌人分批出生，玩家共同守护老鹰。敌人同屏数量按人数增加：`4 + 玩家数` |
| **团队夺基**（Base Battle） | 2v2 ～ 4v4 | 双方各有一只老鹰，先摧毁对方老鹰的一方获胜；可选择是否加入中立 AI |
| **自由混战**（Deathmatch） | 2～8 | 限时或限分，击杀得分，死亡后 3 秒在随机安全点重生 |

## 3. 地图

### 3.1 网格与坐标（与原作 NES 对齐）

| 单位 | 尺寸 | 说明 |
|---|---|---|
| 子像素 `sub` | 1 | 逻辑最小单位，**全部用整数**，1 像素 = 16 sub |
| 微砖 `cell` | 4px = 64 sub | 砖墙可破坏的最小粒度 |
| 半格 `half` | 8px = 2×2 cell | 坦克转向时贴齐的网格 |
| 地块 `tile` | 16px = 2×2 half | 地图编辑单位；坦克占 1 tile |
| 地图 | 13×13 tile（经典）/ 最大 32×32 tile（多人图） | 合作模式用经典尺寸；8 人对战图需要更大 |

### 3.2 地形

| 地形 | 坦克可通行 | 子弹 | 备注 |
|---|---|---|---|
| 砖墙 Brick | ✗ | 摧毁一条宽 4 cell、深 1 cell 的条带 | 按 4×4 微砖逐块破坏 |
| 钢墙 Steel | ✗ | 普通弹被挡；3 星坦克可以摧毁 | 按 half 为单位破坏 |
| 水 Water | ✗ | 穿过 | 拾取「船」道具后可通行（扩展道具） |
| 树林 Forest | ✓ | 穿过 | 遮挡坦克：敌方看不到，自己和队友看到半透明轮廓 |
| 冰面 Ice | ✓（打滑） | 穿过 | 松开方向键后惯性滑行 |
| 老鹰 Eagle | ✗ | 被击中即失败 | 模式相关 |

地图数据用文本或 JSON 存储（每个字符代表一个 tile），方便手工编辑和代码审查。合作模式复刻 35 关的**布局思路**，但关卡本身重新设计。

## 4. 坦克

### 4.1 玩家坦克（星级）

| 星级 | 移速 | 弹速 | 同屏子弹数 | 破钢墙 |
|---|---|---|---|---|
| 0 | 普通 | 普通 | 1 | ✗ |
| 1 | 普通 | 快 | 1 | ✗ |
| 2 | 普通 | 快 | 2 | ✗ |
| 3 | 普通 | 快 | 2 | ✓ |

死亡后回到 0 星。具体数值（每 tick 移动多少 sub）放在 `Core/Rules/TankStats` 里，**整数常量**，按 60Hz 调参。

### 4.2 AI 敌人

| 类型 | 特点 | 血量 |
|---|---|---|
| Basic | 慢速，普通弹 | 1 |
| Fast | 快速 | 1 |
| Power | 快弹 | 1 |
| Armor | 慢速，重甲，受击变色 | 4 |

- 每关第 4、11、18 辆敌人为「闪烁坦克」，被击中时掉落道具。
- AI 行为：随机游走，偏向朝老鹰方向，有概率追击最近的玩家。**AI 运行在服务器上**，使用局内种子化的伪随机数（可复现、可回放）。

## 5. 道具

| 道具 | 合作模式效果 | 对战模式效果 |
|---|---|---|
| 头盔 Helmet | 10 秒无敌护盾 | 同左 |
| 时钟 Clock | 冻结全部敌人 10 秒 | 冻结**敌方队伍** 5 秒 |
| 铲子 Shovel | 老鹰四周变钢墙 20 秒 | 己方老鹰四周变钢墙 |
| 星星 Star | 升 1 星 | 同左 |
| 手雷 Grenade | 摧毁场上所有敌人 | 对敌方全体造成 1 次伤害 |
| 坦克 Tank | +1 命 | 团队 +1 复活次数 |

## 6. 3D 表现

| 项 | 方案 |
|---|---|
| 美术风格 | 低多边形 + 体素（Voxel）。模型用 MagicaVoxel / Blender 制作，导出为 glTF |
| 默认镜头 | **俯视斜角 55°、窄 FOV（约 30°）透视相机**：接近原作的俯视信息量，同时有立体感 |
| 可选镜头 | 第三人称跟随（适合对战模式，有沉浸感），可在设置中切换；**镜头不影响判定** |
| 砖墙破坏 | 微砖用 MultiMesh 批量渲染，被打碎时生成碎块粒子 |
| 树林 | 半透明树冠盖在坦克上方；俯视镜头下按遮挡关系做透明处理 |
| 特效 | 炮口火光、弹道拖尾、爆炸冲击波、护盾气泡、出生闪光 |
| 音频 | 自制芯片音乐风格的配乐和音效（不使用原版音频） |
| HUD | 剩余敌人图标、生命、星级、队伍比分、`net_graph` 网络诊断面板（可开关） |

## 7. 操作

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 移动 | WASD / 方向键 | 左摇杆 / 十字键 |
| 开火 | J / 空格 | A / RT |
| 计分板 | Tab | Back |
| 网络面板 | F3 | — |

规则：同时按下多个方向键时，**后按下的方向优先**（与原作一致），避免斜向输入造成卡顿感。
